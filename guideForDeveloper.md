### Code style & quality
- This project uses ESLint and Prettier. Please run linters locally before pushing.
- Use existing patterns for hooks, context, and slices (see `src/context` and `src/features`).

### Testing
- Add unit tests for new logic. Run tests with `npm test` (if available).

## Where reusable UI components live
- Shared UI components: `src/components/ui`
- Layout components: `src/components/layout`
- Route guard: `src/components/ProtectedRoute.jsx`

For a complete component index and brief descriptions, see `docs/COMPONENTS.md`.

## Running the project locally
1. `npm install`
2. `npm run dev`
3. Open `http://localhost:5173` (Vite default)

## Contact / Questions
If you're unsure where a change belongs, open an issue or ping a maintainer in the PR.
